3. TRACE LIFECYCLE & SCENARIO TRUTHFULNESS
--------------------------------------------------------------------------------
The synthetic trace generator (`createSyntheticTraceForScenario`) rigorously models
all pipeline execution realities according to the Sound Engineer specification:

1. NORMAL Scenario:
   - All 6 stages execute in order (INPUT through PLATFORM_TRANSLATION).
   - INPUT and EVIDENCE complete cleanly.
   - ENGINEERING logs a non-fatal advisory WARNING ("RESONANCE_NEAR_LIMIT", severity WARNING).
   - Downstream stages (SEMANTIC_DESIGN, VALIDATION, PLATFORM_TRANSLATION) complete successfully.
   - Overall trace status derives strictly as WARNING (WARNING !== FAILED).
   - Verified by test 2.

2. FAIL Scenario:
   - Upstream ENGINEERING layer encounters a simulated fatal failure
     ("UAT_FAULT_INJECTION_FAIL", severity ERROR).
   - Downstream stages (SEMANTIC_DESIGN, VALIDATION, PLATFORM_TRANSLATION) are explicitly
     marked SKIPPED with diagnostic code "SKIPPED_DUE_TO_FAILURE".
   - Downstream stages produce NO fabricated outputs (output is undefined).
   - Overall trace status derives as FAILED.
   - Verified by test 3.

3. TIMEOUT Scenario:
   - Upstream ENGINEERING layer exceeds maximum time budget ("SHADOW_EXECUTION_TIMEOUT").
   - Downstream stages are marked SKIPPED without fake completion.
   - Overall trace status derives as FAILED.
   - Verified by test 4.

4. HOLD / RUNNING Scenario:
   - Upstream stages (INPUT, EVIDENCE) are completed.
   - ENGINEERING layer is actively RUNNING (startedAt is set; completedAt and durationMs
     remain undefined; no fabricated timing).
   - Downstream stages are PENDING (unstarted; no timing fabricated).
   - Overall trace status derives as RUNNING.
   - Summed layer duration strictly tallies completed stages only.
   - Verified by test 5.

5. CANCEL Scenario:
   - User or system aborts active execution during ENGINEERING stage.
   - Checkpoint records status "cancelled" with diagnostic "SHADOW_RUN_CANCELLED".
   - Downstream stages are marked SKIPPED.
   - Overall trace status derives as CANCELLED (never conflated with FAILED).
   - Verified by test 6.

5. ISOLATION & ZERO SIDE-EFFECT GUARANTEES
--------------------------------------------------------------------------------
1. Protection of CURRENT Production Engine:
   - CURRENT Tone Translation (`translateTone`, `buildToneProfile`, `presetParser`,
     `presetExporter`, AT5 parameter manifest) remains 100% isolated.
   - CURRENT Tone Translator controls (Generate, Refresh, Clear, Export .at5p)
     function identically regardless of whether a Shadow trace exists or is open.

2. Zero AI / Execution Side Effects:
   - `RunTraceInspector` contains ZERO calls to `geminiService`, LLM endpoints,
     audio analysis DSPs, or network APIs.
   - Purely in-memory, read-only presentation.

3. Session Storage Isolation:
   - Verified by test 19: Working session persistence (`saveWorkingSession`,
     `loadWorkingSession`) does NOT persist `shadowState`, `shadowTrace`, or
     inspector modal state.
   - LocalStorage and SessionStorage schemas remain completely unpolluted.

4. Race Condition & Stale Run Immunity:
   - App-level `activeShadowRunIdRef` ensures that rapid consecutive shadow runs
     silently discard delayed completion callbacks from prior runs, preventing
     stale traces from overwriting newer traces.
