SCENARIO ID: UAT-SCEN-05
SCENARIO NAME: Conflicting High-Quality Sources (Loudspeaker Cone Breakup: Straight vs Curved Cone Dispersion)
--------------------------------------------------------------------------------
INPUT / TEST FIXTURE:
Two authoritative, high-rigor engineering sources make directly competing assertions regarding high-frequency
beaming in guitar loudspeaker drivers:
- Source A: Classic Text (Olson, "Acoustical Engineering", 1957; Beranek, 1954):
  Asserts that a 12-inch circular piston loudspeaker radiates as a rigid plane radiator, exhibiting severe high-frequency
  beaming above the critical frequency fc = c / (pi * a) ~= 1.8 kHz, producing a sharp 18 dB/octave off-axis attenuation above 2 kHz.
- Source B: Modern Finite-Element Loudspeaker Transducer Research (AES Convention Paper 2018 / Klippel, "Loudspeaker Non-Linearities"):
  Demonstrates that modern guitar loudspeakers with ribbed, curvilinear paper cones and decoupled dust caps do NOT behave as rigid
  pistons; circumferential modal breakup decouples the outer cone, preserving broad off-axis dispersion up to 3.2 kHz before beaming occurs.

FROZEN CONTRACTS UNDER TEST:
- Exact Eight Canonical Knowledge Entities: Mandatory instantiation of `ConflictRecord`.
- Conflict Architecture: System must preserve professionally legitimate disagreement without picking an arbitrary winner,
  averaging equations, or suppressing the conflict from runtime context.
- OperationalBoundary Resolution: Investigates whether divergence is rooted in distinct physical boundary conditions.
- Epistemic Discipline: "Preserve minority dissent and competing hypotheses without workflow lockup."

ARCHITECTURAL PATH:
SourceDocument A & B -> Extraction -> Two Competing KnowledgeClaims (KCL-TRAN-BEAM-001A and KCL-TRAN-BEAM-001B) ->
Ingestion Conflict Detector -> ConflictRecord (CR-TRAN-MODAL-001) -> OperationalBoundary Analysis ->
Governance Adjudication -> Retrieval Engine.

EXPECTED BEHAVIOUR:
The ingestion pipeline detects a direct factual contradiction regarding the critical beaming frequency (1.8 kHz vs 3.2 kHz).
The system:
1. Instantiates a `ConflictRecord` (CR-TRAN-MODAL-001, type: `EMPIRICAL_BOUNDARY_DIVERGENCE`).

When an OperationalBoundary specifies an unbounded physical parameter (e.g. acoustic air attenuation
valid for any distance d >= 5.0 meters with no upper limit, or an amplifier operating at any SPL below

(e.g. `valid_envelope: { distance_m: [5.0, null] }`). This avoids arbitrary large floating-point
constants while remaining fully compatible with TypeScript AST typing.
IMPACT ON FREEZE: ZERO. The architecture handles both forms identically during evaluation.
